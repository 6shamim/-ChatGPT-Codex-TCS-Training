# Codex Training Test V1

A small, self-contained starter project for testing Codex coding workflows.

## Run

```bash
python3 -m unittest discover -s test -v
```

## Contents

- `src/training_test.py` — deterministic training questions and scoring.
- `test/test_training_test.py` — basic behavior tests.

This V1 intentionally uses only the Python standard library.
